# Physik4Physio

- `Raetselreise-Physik.html` – Schüler-App (Rätselreise Physik, Physiotherapie-Ausbildung)
- `Raetselreise-Physik-Lehrkraft.html` – Lehrkraft-Version derselben App: alle Räume offen,
  - **16 Unterrichtsstunden à 60 min** (2 pro Raum) mit Phasenschema Methodenkiste · Warm-up ·
    Einstieg · Präsentation des Hefteintrags · Übungsphase · Ergebnissicherung (Profil → „Lehrkraft-Werkzeuge“ → 📅)
  - **16 Hefteinträge** (2 pro Raum) für die Tafel: schrittweise aufdeckbar, mit Vortragsnotizen und Druck
  - **Schulaufgaben-Werkstatt** mit 104 Aufgaben im Physio-Kontext (Prüfungsaufgaben, Quiz, Praxisfälle,
    Zuordnen/Reihenfolge/Einsortieren) → Erwartungshorizont, Einschätzungsmatrix, Notenschlüssel, Word-/Druck
  - **Antwortschlüssel** aller Quiz-, Karteikarten- und Prüfungsaufgaben
